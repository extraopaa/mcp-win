# Identité visuelle MCP Win

PNG originaux fournis par le propriétaire du projet le 20 octobre 2026, conservés sans modification :

- icon-original.png : symbole couleur seul.
- logo-horizontal.png : logo horizontal avec slogan.
- logo-primary.png : logo principal vertical.
- logo-monochrome-dark.png : variante sombre.
- logo-monochrome-light.png : variante claire.

Le script scripts/build-brand-icons.ps1 convertit le symbole fourni en ressources techniques : cadrage des marges transparentes, centrage, mise à l’échelle et encodage. Aucun élément graphique n’est redessiné. Il produit ui/brand/icon.png, ui/brand/favicon.png, icons/icon.png et l’ICO Windows multi-résolution.

L’interface sombre utilise le symbole couleur et conserve le nom de l’application en texte clair pour sa lisibilité.
