# Lato

Lato Regular, Bold, Italic et BoldItalic, par tyPoland / Łukasz Dziedzic, sont embarquées sans modification pour la génération PDF. Les quatre variantes sont disponibles dans Typst ; le générateur PDF simple utilise Regular. Licence SIL Open Font License 1.1 : voir `OFL.txt`, également distribuée dans le paquet Windows.

Source du fichier : https://github.com/google/fonts/tree/main/ofl/lato
