# MCP Win v0.4 — préversion 0.4.0-preview.1

L’application donne à une IA distante des outils locaux pour chercher, lire, créer et corriger les fichiers des dossiers partagés. Cette préversion conserve le tunnel Cloudflare chiffré, le jeton MCP obligatoire et l’alternative frp avec certificat vérifié. Les sources de cette préversion sont publiées sur GitHub.

## Chercher avant de lire

- `search_files` parcourt les textes UTF-8, PDF avec texte, DOCX, PPTX et tableurs pris en charge. Il retourne des extraits de 400 caractères avec chemin, page, feuille et ligne. Les lignes Excel tiennent compte du début réel de la plage utilisée, y compris après la ligne 5 000.
- `query` est une chaîne littérale par défaut ; `use_regex:true` active les expressions régulières Rust. Casse ignorée par défaut, `case_sensitive:true` pour la respecter.
- `glob_pattern` filtre les fichiers, par exemple `**/*.pdf`, `2024/*.xlsx`. `max_matches` vaut 25 par défaut (100 maximum). `max_files` borne le parcours par appel (200 par défaut, 1 000 maximum). Continuer avec `next_cursor` jusqu’à null.
- L’index est un cache local en mémoire, invalidé par SHA256 du contenu. Il est reconstruit au besoin, sans API externe, sans embeddings payants et sans base persistante de contenu.
- Les PDF scannés ne sont pas OCRisés automatiquement pendant une recherche. `ocr_file` traite une page sélectionnée. Les documents illisibles ou hors limites sont signalés dans `skipped`.
- Cache : 64 Mio/512 documents ; texte extrait : 16 Mio par document ; tableur : 500 feuilles, 2 millions de cellules par feuille. Parcours limité à 50 000 entrées/64 niveaux ; suivre `tree_truncated`, `skipped` et les curseurs. Aucune couverture exhaustive n’est annoncée si une limite est atteinte.

```json
{"name":"search_files","arguments":{"query":"Total TTC|Facture","use_regex":true,"glob_pattern":"2024/**/*.pdf","max_matches":15}}
```

`list_files` accepte `recursive`, `glob_pattern`, `compact`, `offset` et `limit` (500 maximum). `compact:true` renvoie les chemins relatifs, avec `/` final pour les dossiers. Les liens et l’historique sont exclus.

## Réduire le contexte envoyé à l’IA

| Outil / option | Résultat |
| --- | --- |
| `get_document_outline` | H1–H3 Markdown/Word, signets PDF ou titres des diapositives ; nombre de mots/pages. Excel : noms des feuilles. Un PDF sans signets n’a pas de plan inventé. |
| `read_file(line_range:[100,150])` | Seulement ces lignes inclusives, numérotées à partir de 1. |
| `read_file(matching_regex:"Total TTC")` | Seulement les lignes correspondantes ; combinable avec line_range. |
| `read_file(compact:true)` | CSV/TSV ou tableur : colonnes, types estimés sur trois exemples, trois lignes et nombre de lignes. Première ligne utilisée supposée être l’en-tête ; formules non recalculées. CSV virgule/point-virgule et TSV pris en charge. |
| `ocr_file(plain_text_only:true)` | Texte reconstitué par paragraphes, sans objets de mots/coordonnées ; mode par défaut. offset/limit pour continuer. false conserve la sortie détaillée. |
| `inspect_office_package` | Parties paginées ou XML fenêtré, offset/limit/matching_regex ; 8 000 caractères par défaut au lieu d’un XML complet. |

Une lecture ordinaire renvoie 8 000 caractères par défaut, maximum 50 000. Les gains réels en tokens dépendent du document ; aucun multiplicateur garanti.

## Fusionner et extraire des pages PDF

`merge_pdfs` reçoit `inputs`, un tableau de `{path, pages?}`, et `output_path`. `split_pdf` reçoit `path`, `pages` et `output_path`. Les pages commencent à 1 ; exemples : `3-5`, `1,3,8-10`.

```json
{"name":"merge_pdfs","arguments":{"inputs":[{"path":"devis-a.pdf"},{"path":"devis-b.pdf","pages":"1-2"}],"output_path":"devis-regroupes.pdf"}}
```

Les sources restent intactes et la sortie doit être nouvelle. Maximum 50 sources/2 000 pages, 25 Mio par source et sortie. Il s’agit de copies des pages : la validité des signatures et la structure documentaire globale ne sont pas conservées dans la nouvelle compilation.

Les PDF avec widgets de formulaire sont refusés par défaut pour éviter de perdre leurs champs. `flatten_forms:true` est réservé à une demande explicite de figer le résultat ; les apparences sont peintes dans les pages, puis les widgets et AcroForm sont retirés. Le PDF source reste interactif.

## Remplir les AcroForms

1. `inspect_pdf_form(path)` retourne les vrais champs canoniques, leurs noms complets, types, valeurs, options et SHA256. Pagination `offset/limit` ; aperçus et listes d’options bornés.
2. `fill_pdf_form` prend `path`, `output_path`, `expected_sha256` et `values` : un objet associant nom de champ et valeur.
3. Vérifier le résultat avec `render_pdf_page`. Les originaux ne sont jamais écrasés.

```json
{"name":"fill_pdf_form","arguments":{"path":"formulaire.pdf","output_path":"formulaire-rempli.pdf","expected_sha256":"EMPREINTE_RETOURNEE","values":{"client.name":"Élodie Noël","approved":true,"department":"Support"}}}
```

Texte Lato (latin/grec/cyrillique), cases à cocher, groupes radio et listes de choix sont pris en charge. Pour les radios et cases avec plusieurs états, fournir le nom d’export retourné par l’inspection. `font_size` fixe la taille maximale (12 pt par défaut) ; réduction jusqu’à 4 pt si nécessaire, puis refus plutôt qu’un texte tronqué.

Les valeurs `/V` canoniques, widgets et apparences `/AP` sont mises à jour ensemble et vérifiées après réouverture. Le document reste interactif. Les formulaires XFA, PDF chiffrés/signés, widgets orphelins ou ambigus, champs verrouillés, peignes/textes enrichis et widgets tournés sont refusés avec diagnostic. Un formulaire dessiné ou scanné n’est pas un AcroForm. Les extracteurs PDF ordinaires peuvent ignorer les valeurs interactives : les relire avec `inspect_pdf_form`.

## Archives locales

- `inspect_archive(path,offset?,limit?)` : inventaire sans extraction de ZIP, TAR, TAR.GZ/TGZ et 7z, tailles et `unsafe_entry`.
- `extract_archive(path,entries,destination)` : seulement les fichiers explicitement sélectionnés (1 à 20), sans écrasement. Les sous-dossiers nécessaires sont créés dans le partage writable. Vérifier `complete` et `written`.
- `create_archive(paths,output_path)` : regrouper 1 à 100 fichiers dans ZIP/TAR/TAR.GZ/7z en conservant leurs chemins relatifs.

Sources cumulées et contenu décompressé limités à 100 Mio, 10 000 entrées, 25 Mio par fichier et par sortie. Liens, jonctions, anti-items, noms Windows réservés, historique et traversées sont interdits à l’extraction. Pas de mot de passe. Une erreur ou interruption d’écriture peut laisser des sorties déjà créées ; consulter `written` ou relister la destination avant de recommencer.

Archives, inspection/remplissage de formulaires et fusion/extraction PDF s’exécutent hors du processus de l’interface : job Windows limité à 768 Mio, un processus et 30 secondes. Cela inclut le décodage des en-têtes 7z.

## SQLite et DuckDB en lecture seule

`query_sqlite` et `query_duckdb` acceptent `folder`, `path`, `query` optionnel et `max_rows` (50 par défaut, 500 maximum). Sans query, ils décrivent le schéma. Bases jusqu’à 4 Gio, sans conversion CSV et sans chargement complet en mémoire.

SQLite utilise `mode=ro&immutable=1`, query_only, trusted_schema désactivé, un authorizer restrictif et un budget de calcul. `parameters` fournit les valeurs positionnelles `?`. ATTACH, écritures et extensions sont refusés. Les blobs sont décrits par taille et les textes limités à 2 000 caractères par cellule.

DuckDB 1.5.6 est intégré sous licence MIT, en `-readonly -safe -no-init`, dans un processus limité (10 secondes/768 Mio). Aucune lecture de fichier externe, requête réseau, extension installée ou commande système. Les résultats trop volumineux sont refusés ; sélectionner moins de colonnes ou utiliser `substr`.

Les bases avec WAL/journal actif sont refusées : fermer l’application propriétaire ou partager un export/checkpoint cohérent. Ces outils ne servent pas à contourner les verrous d’une base en cours d’utilisation.

## Modifier par patch et annuler localement

`apply_file_patch(path,expected_sha256,patch)` applique un diff unifié exact à un texte UTF-8. Avant écrasement, une copie est conservée dans `.mcp-history`. Un conflit de SHA ou de contexte interrompt l’opération.

Pour OOXML, ajouter `part` (ex. `word/document.xml`) et un `output_path` nouveau : la source reste intacte et seules les modifications XML ciblées sont appliquées. Le patch est limité à 256 Ko ; le XML résultant reste soumis aux validations OPC existantes. Il ne s’agit pas d’un exécuteur de commandes ni d’un correcteur approximatif.

Dans l’interface : **Historique** à côté d’un dossier, puis **Restaurer cette version**. Arrêter le MCP avant restauration. Cette action locale explicite reste disponible même si le partage est en lecture seule pour l’IA ; elle ne modifie pas les permissions distantes. La restauration conserve aussi l’état qu’elle remplace. Historique limité à 512 Mio par dossier ; s’il est plein, l’écriture est refusée plutôt que supprimer silencieusement les copies. Le dossier est réservé et n’est pas exposé via MCP.

Les outils Office produisaient déjà des copies : leur original reste la sauvegarde. Une nouvelle copie ne crée donc pas artificiellement une version supplémentaire de la source.

## Modèles d’entreprise

Déposer les modèles dans un sous-dossier partagé dédié, par exemple `templates/rapport/`. `list_templates` les liste ; `inspect_template` indique les placeholders ou références data. Ne pas mélanger des documents privés sans rapport avec les assets d’un modèle.

- **Typst** : `.typ` avec `#data.title`, `#data.items`, etc. `template` remplace `source` dans `create_designed_pdf` et `validate_designed_pdf` ; `data` est un objet JSON. Les données sont écrites dans un fichier JSON temporaire, jamais évaluées comme du code Typst. Images, polices et imports voisins du sous-dossier sont copiés (maximum 50 assets/50 Mio), ou fournis explicitement dans assets.
- **Word** : `.dotx` ou `.docx`, placeholders `{{client}}`, `{{reference}}`… Le remplacement fonctionne même si un placeholder est coupé entre plusieurs segments de style. Styles, tableaux et mise en page existants sont conservés ; un DOTX devient un vrai DOCX.
- **PowerPoint** : `.potx` ou `.pptx`, mêmes placeholders ; sortie PPTX.
- **Excel** : `write_spreadsheet(template:"templates/modele.xlsx",cells:[...])` part d’un classeur et conserve sa structure/styles. `template` et `input_path` sont exclusifs.

`create_from_template` génère PDF/DOCX/PPTX ; `create_document` accepte aussi template/data. Pour Office, les valeurs sont scalaires (texte/nombre/booléen/null), pas des boucles de lignes ; utiliser les outils OOXML pour ces transformations avancées. Les clés manquantes sont signalées avant d’enregistrer. Les modèles contenant macros, objets incorporés ou relations externes actives sont refusés.

## Connexion

Cloudflare Quick Tunnel reste gratuit et sans compte, avec URL temporaire ; le relais Cloudflare peut voir le contenu et ne fournit pas de garantie de disponibilité/SSE. Le client IA doit accepter Streamable HTTP JSON et un header Bearer. L’alternative frp exige un certificat vérifié. Les boutons copient séparément le jeton, `Bearer <jeton>` et le JSON `{"Authorization":"Bearer <jeton>"}` prêt pour « Headers sécurisés ».

## Validation

Les tests utilisent des dossiers temporaires et des données fictives : recherche, tableaux tardifs, pagination, patch/conflit/restauration, modèles, fusions, AcroForms canoniques/widgets/apparences, archives malveillantes et SQL en lecture seule. Les protections du tunnel et des requêtes HTTP sont conservées. Voir aussi SECURITY-V04.md.
