Informations de connexion

Renseignez séparément l’adresse et l’en-tête Authorization dans votre application IA.

Démarrez le MCP pour obtenir l’adresse
L’adresse est disponible lorsque le serveur est démarré.
Authorization: Bearer
Authorization: Bearer <votre jeton>
Le jeton est confidentiel et enregistré dans vos préférences locales.

frpc est intégré. Votre serveur frps doit router ce domaine avec HTTPS, un certificat CA et un nom TLS vérifiés. Les exemples sont fournis dans relay/.

Réglages de connexion
Réglages enregistrés
Cloudflare Quick Tunnel est intégré, gratuit et sans compte. Les deux segments Internet sont chiffrés ; le relais peut voir le contenu. Adresse temporaire, disponibilité non garantie, réponses JSON ; SSE indisponibles.
Le jeton Bearer est obligatoire. Votre relais personnel peut voir le contenu transmis. Arrêtez le serveur avant de modifier les réglages.
