Informations de connexion

Renseignez séparément l’adresse et l’en-tête Authorization dans votre application IA.

Démarrez le MCP pour obtenir l’adresse
L’adresse est disponible lorsque le serveur est démarré.
Authorization: Bearer
Authorization: Bearer <votre jeton>
Le jeton est confidentiel et enregistré dans vos préférences locales.

frpc est intégré. Votre serveur frps doit router ce domaine avec HTTPS, un certificat CA et un nom TLS vérifiés. Les exemples sont fournis dans relay/.

Réglages de connexion
Réglages enregistrés
Cloudflare Quick Tunnel est intégré, gratuit et sans compte. Les deux segments Internet sont chiffrés ; le relais peut voir le contenu. Adresse temporaire, disponibilité non garantie, réponses JSON ; SSE indisponibles.
Le jeton Bearer est obligatoire. Votre relais personnel peut voir le contenu transmis. Arrêtez le serveur avant de modifier les réglages.

Une recherche qui se souvient

L’index conserve localement le texte extrait pour éviter de recommencer à chaque conversation. Les résultats citent leurs fichiers, pages et empreintes. Les scans demandent encore un OCR explicite.

L’IA utilise index_folder et search_index. Actualisez l’index après ajout ou modification de documents. Le contenu de l’index reste dans les données privées de l’application.

Les tâches de votre assistant

Suivez la génération de plusieurs livrables et reprenez une tâche interrompue.

L’IA prépare les étapes avec start_workflow. Arrêter le MCP suspend les tâches. Pour reprendre, redémarrez le MCP ; pour annuler leurs fichiers, arrêtez-le. Les fichiers modifiés depuis la tâche sont protégés.

Propositions de modification

Comparez les changements avant de les appliquer.

Les propositions ne changent aucun fichier partagé. Arrêtez le MCP pour appliquer, refuser ou annuler une révision. L’empreinte source est revérifiée au moment de l’application.
