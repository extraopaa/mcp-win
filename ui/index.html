Mode de connexion

Le client du tunnel est écrit en Rust. Le relais public peut être indisponible ou demander un en-tête de contournement ; utilisez votre propre relais pour une adresse stable.

Le relais termine le HTTPS et peut voir le trafic. Le protocole localtunnel utilise une liaison TCP non chiffrée entre le relais et ce PC.

frpc est livré avec l'application. Votre serveur frps doit router le domaine vers ce client, avec HTTPS sur le relais. Les exemples de déploiement sont fournis dans le dossier relay/.

Sans authentification, toute personne possédant l’adresse publique peut lire les dossiers partagés.
