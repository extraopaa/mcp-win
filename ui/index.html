Connexion extérieure

Choisissez votre tunnel. L'application s'occupe du démarrage.

Mode de connexion

Cloudflare Quick Tunnel est intégré : aucune installation ni connexion à un compte. Les deux segments Internet sont chiffrés. Cloudflare peut voir le contenu transmis. Adresse temporaire, disponibilité non garantie, réponses MCP JSON ; SSE indisponibles.

frpc est livré avec l'application. Votre serveur frps doit router le domaine vers ce client, avec HTTPS sur le relais. Les exemples de déploiement sont fournis dans le dossier relay/.

Jeton obligatoire : l’adresse seule ne permet pas de lire les fichiers.

Le jeton est enregistré dans vos préférences locales. Arrêtez le MCP avant de modifier les réglages.

Dans votre application IA

Ajoutez un serveur MCP distant avec le transport Streamable HTTP.

AdresseDémarrez le MCP pour obtenir l'adresse
AuthentificationAuthorization: Bearer <jeton>

Collez la configuration JSON dans « Headers sécurisés (JSON) ». Elle contient uniquement Authorization avec Bearer et votre jeton. Renseignez l’adresse du serveur séparément et conservez le jeton privé. Certains clients ne permettent pas les en-têtes personnalisés ou exigent OAuth : leur compatibilité dépend du client.
